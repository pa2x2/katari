# The libraries libmpv takes from the system and opens on first use instead of linking them (see lazy-library.py),
# with every function of theirs mpv and FFmpeg call. A function's fallback, after "=", is what it returns when the
# library or one of these functions is missing; it is 0 (null, false, nothing) unless given. The first call each
# feature makes into its library must fail with its fallback, so the feature gives up before using anything else.
#
# check-library.py fails the build when the library needs a function from outside glibc: add it to its library
# here, after checking what it returns when the library is missing.
